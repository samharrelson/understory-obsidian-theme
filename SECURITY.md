# Security Policy

Understory is a CSS theme for Obsidian and has a relatively small security surface, but security-sensitive reports are still welcome.

## Supported versions

The latest public release is the supported version for security-related fixes.

Older releases may not receive security updates.

## Reporting a vulnerability

Please do **not** open a public GitHub issue for a security-sensitive report.

Instead, contact:

**Sam Harrelson**  
sam@samharrelson.com

Include:

- a description of the issue;
- the affected Understory version;
- the affected Obsidian version and operating system;
- steps to reproduce the issue, if known;
- any relevant screenshots, logs, or proof-of-concept material.

Please avoid including secrets, credentials, private vault contents, or other sensitive personal information unless they are essential to understanding the report.

## What to expect

Reports will be acknowledged as reasonably possible and evaluated for relevance to Understory.

Because Understory is primarily theme CSS, some reports may ultimately concern Obsidian itself, a plugin, Electron, the operating system, or another dependency. If that appears to be the case, the report may be redirected to the appropriate project.
