# Changelog

## 0.2.1

- Increased sidebar navigation contrast slightly in both light and dark modes.
- Strengthened the active-tab state without introducing a loud accent.
- Added a subtle moss underline to the current tab.
- Preserved the core palette, typography, reading width, and callout vocabulary.

## 0.2.0

- Added Understory-native `field`, `finding`, and `carry-forward` callouts.
- Harmonized built-in callout colors with the moss / gold / rust palette.
- Added quieter graph, scrollbar, checkbox, table, search, and unresolved-link treatments.
- Added a subtle active-file marker in the file tree.

## 0.1.0

- Initial release.
- Warm parchment light mode.
- Walnut-shell dark mode.
- Bookish note typography with quiet interface chrome.
